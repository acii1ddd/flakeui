# flakeui

Компактный оверлей для Windows с дождём, снегом и раннером на DirectX. Кораблик прыгает между окнами и значками рабочего стола. Снег оседает на панели задач, а капли дождя реагируют на движение окон.

## Запуск

Скачайте **flakeui-0.1.0-win-x64.zip** со [страницы релизов](https://github.com/acii1ddd/flakeui/releases), распакуйте целиком в доступную для записи папку и запустите **NeonRainOverlay.exe**. Сборка предназначена для 64-битной Windows 10/11 с DirectX 11 и включает среду .NET Desktop.

Двойной щелчок по сакуре в трее открывает настройки. Дождь и снег заменяют друг друга, раннер включается независимо. Щелчок по дорожке ползунка сразу выбирает значение. Настройки сохраняются в `%LOCALAPPDATA%\flakeui\settings.json`.

Постоянные рамки рисует включённый в архив [Tacky Borders 1.6.0](https://github.com/luke-you/tacky-borders/releases/tag/v1.6.0). Его можно остановить отдельно из трея. Чтобы удалить портативную версию, завершите оба процесса и удалите распакованную папку.

## Сборка

На Windows с .NET 9 SDK выполните `dotnet build -c Release`. Для создания автономного ZIP запустите `.\Publish-Release.ps1` из PowerShell. Сценарий скачивает закреплённую версию Tacky Borders и проверяет SHA-256. Архив появится в `artifacts`.

Тесты `--smoke-snowbank` и `--smoke-runner-timing` проверяют поведение эффектов. Параметр `--benchmark-native` запускает сравнение при движении отдельного окна.
